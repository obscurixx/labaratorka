# Лабораторная работа

## Базовые инструменты профессии на практике

Дисциплина: Основы профессиональных IT-компетенций

Направление: Специалист по интеграции искусственного интеллекта

## Цель работы

Познакомиться с базовыми онлайн-инструментами IT-специалиста и освоить их практическое применение.

## Используемые инструменты

- GitHub — хранение кода и контроль версий.
- Replit — онлайн-среда программирования на Python.
- Google Colab — работа с Python и анализ данных.
- ChatGPT — помощь в изучении и объяснении кода.

## Практическая работа

В рамках лабораторной работы выполняются следующие задания:

1. Создание репозитория GitHub.
2. Работа с ветками, коммитами и Pull Request.
3. Запуск программы на Python в Replit.
4. Работа с библиотекой pandas и набором данных Iris в Google Colab.
